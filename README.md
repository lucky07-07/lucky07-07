Imbalance-aware transformer ensemble for fine-grained rice leaf disease recognition.

### Tech

`PyTorch` `ViT` `Swin-T` `ConvNeXt` `Optuna`

### Highlights

* 🎯 97.48% accuracy · 0.9750 macro-F1
* 🧪 Ensemble learning with TTA
* ⚖️ Optimized for class imbalance
* 🔍 Grad-CAM explainability
